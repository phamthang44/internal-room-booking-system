Room booking email templates

This file is a lightweight reference for what variables each Thymeleaf email template expects. It intentionally avoids hard-coded example people/booking data so it stays reusable across projects.

mail/otp-code.html

  • appName
  • greeting (optional)
  • message (optional)
  • otpCode
  • expiryMinutes
  • supportEmail
  • helpCenterUrl / privacyPolicyUrl / termsUrl (optional)

mail/reset-password-success.html

  • appName
  • userName (optional)
  • userEmail (optional)
  • resetTimestamp
  • loginUrl
  • supportEmail
  • helpCenterUrl / privacyPolicyUrl / securityUrl (optional)

mail/welcome.html

  • appName
  • userName (optional)
  • welcomeMessage (optional)
  • ctaUrl + ctaText
  • supportEmail
  • helpCenterUrl / privacyPolicyUrl / unsubscribeUrl (optional)
